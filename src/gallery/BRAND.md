# Actual Blocks brand assets

These vectors are the Actual Blocks identity derived from the Actual CSS brand pack:

- `actual-blocks-mark.svg` — the compact transparent header mark: triangle, bar and the square “posé” inside the triangle.
- `actual-blocks-icon.svg` — the standalone rounded-square mark with the square “posé” on the inner base of the triangle; also copied to `dist/favicon.svg`.
- `actual-blocks-wordmark.svg` — the full wordmark with the square separator, kept as a brand asset but not used in the compact header.

Provenance:

- Geometry comes from the `actual_blocks_positions_du_carre.svg` concept (`Posé` variant) and `pistes_logo_actual_blocks.svg` wordmark.
- Paths and colors are preserved; the square inside the wordmark's A was added from the `Posé` geometry so the mark and the wordmark agree.
- The brand colors are aubergine `#52396F`, violet `#9B7BCB`, pale `#F4EFFA`, and favicon square `#C4A8E8`.
- The logo is outlined, so no webfont is required.

The gallery loads these assets; block previews and copied blocks do not.
